# Data

This folder contains the raw historical stock market dataset used in the project.

- **File:** AL_Rjehei.csv
- **Source:** [Kaggle – Al Rajhi Stock Data Analysis (2010–2025)](https://www.kaggle.com/datasets/hassanjameelahmed/al-rajhi-stock-data-analysis-20102025)
- **Coverage:** March 2010 – December 2025
- **Records:** 3,926 daily trading records

The dataset was cleaned and prepared before being used in Power BI.
